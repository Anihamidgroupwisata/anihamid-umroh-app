# PT. ANIHAMID GROUP WISATA

Aplikasi prototype dashboard jamaah publik dan admin untuk pendaftaran perjalanan ibadah.

## Fitur utama
- Dashboard publik tanpa login
- Daftar paket dan detail paket
- Form pendaftaran jamaah multi-step tanpa login
- Pilihan agen aktif / referensi / manual
- Panel admin untuk melihat pendaftaran dan mengelola konten
- Penyimpanan data lokal menggunakan `localStorage`

## Cara menjalankan
1. `npm install`
2. `npm run dev`
3. Buka `http://localhost:5173`
